推敲 (suikou)

note でエッセイや小説を書く人のための、校閲・編集者視点の指摘ツール。

AI に書かせるためのツールではありません。書き上げた原稿を外から眺めるための鏡です。このツールは答えを出しません。指摘と、考えるための視点だけを返します。

使い方

index.html をダブルクリックしてブラウザで開くだけです。インストールもビルドも不要です。

ブラウザの設定でローカルファイルの読み込みが制限されている場合は、同梱のサーバーを使ってください。

powershell -ExecutionPolicy Bypass -File .\serve.ps1
# http://127.0.0.1:8787/ を開く

ルールが意図どおり動いているかは test.html を開くと確認できます。

キーボード

F8 / Shift + F8次 / 前の指摘へ移動
Ctrl + S本文を Markdown で保存

原稿と設定はブラウザの localStorage に自動保存されます。テーマは右上の ☾ / ☀ でも切り替えられ、既定は明るいテーマです。

タブレット・スマホ

幅が広い画面（PC や、横向きのタブレット）は、これまでどおり執筆と指摘が並びます。

幅がおよそ 720px 以下では、下の「執筆」「指摘」で画面を切り替えます。プリセットや取り込みは右上の「メニュー」に入っています。指摘をタップすると執筆側の該当箇所へ移ります。

同じアドレスを開いても、原稿はその端末のブラウザの中に保存されます。PC の下書きはスマホには自動では出ません。

GitHub で公開する（スマホの Chrome で開く）

アプリのファイルだけを GitHub Pages に置くと、https://（アカウント）.github.io/（リポジトリ名）/ で開けます。原稿は GitHub に上がりません。

  1. GitHub で新しいリポジトリを作る（無料なら公開。非公開の Pages は有料プランが必要です）
  2. このフォルダ一式をそのリポジトリに上げる（ビルドは不要です）
  3. リポジトリの Settings → Pages で、Source を Deploy from a branch、Branch を main（または master）の / (root) にする
  4. 数分待つと URL が出ます。タブレット／スマホの Chrome で開き、ブックマークします

ルートの .nojekyll で Jekyll を切ってあります。パスは相対指定なので、サブフォルダ型の Pages でも動きます。

設計の前提

1. 既定では通信しない

ルールはすべて辞書と規則で、この端末の中だけで動きます。既定の状態でネットワークに出ることはありません。

  • R-18 を含むどんな原稿も、検閲も送信もされない
  • 未公開の原稿が第三者のサーバーに残らない
  • なぜ指摘されたのかが全部読める
  • オフラインで動き、無料で、API の仕様変更で壊れない

規則で扱えないのは文意です。そこだけを言語モデルに読ませる口を別に用意しています（「AI 補助」）。既定はオフで、有効にしてもボタンを押した瞬間しか送信しません。

2. 本文を書き換えない

自動修正機能はありません。言い換え候補は出しますが、置換ボタンは付けません。候補はクリックでコピーできるだけです。

既定では候補を伏せています（設定で変更可）。「候補を見る」を押すまで表示されないので、まず自分の言葉で考えられます。

例外は表記統一だけです。「できる／出来る」の統一は、設定でオンにすると一括置換ボタンが出ます。既定はオフです。

3. 「間違い」と「気になる箇所」を分ける

段階意味
要修正直したほうがいい。誤字、括弧の閉じ忘れ、個人情報の混入など
検討読者がつまずく可能性がある。長文、表記の揺れ、重言など
確認意図的ならそのままで構わない。同音異義語、受け身の多用など
参考気づいていないかもしれない傾向。五感の偏り、語彙の多様性など

4. 見た指摘は消せる

ボタン動作
✓ 対応済み直した・読んだ指摘を隠す。別の場所を編集しても印は外れません
⊘ 今後も無視ルールと語の組み合わせで登録する。別の原稿でも出なくなる

隠した指摘はフィルタの「片付け済み」で呼び戻せます。まとめて戻すには設定タブの「片付けた指摘」を使ってください。

note との受け渡し

日常は note のエディタからコピーして貼る／推敲から「note用HTMLをコピー」して貼る、の往復です。一括は WXR / MT の書き出しと、note のエクスポート ZIP の読み込みです。

note → 推敲

  • note のエディタで Ctrl+A → Ctrl+C し、推敲に貼る（または「取り込み ▾」）。HTML から見出し・引用・箇条書き・太字などを記法に戻します。

  • note のエクスポート ZIP を解いた XML / MT形式の txt は「取り込み ▾」から開けます。

note風プレビュー

タイトル欄の下の「note風プレビュー」で、載せたときの見え方に切り替わります。指摘をクリックすると、その段落が強調されます。

表・脚注・斜体・取り消し線・3 階層以上の見出し・入れ子リストは note に無いので、渡し方にかかわらず警告します。

何を見ているか

ルールは設定タブで個別にオン／オフ、深刻度、閾値を変えられます。分類は次のとおりです。

  • 誤字・誤用 — 慣用句の誤り、ら抜き・さ入れ、二重敬語、重言、同音異義語、括弧、記号、副詞の呼応
  • 表記の揺れ — できる／出来る など、敬体と常体、一人称、数、句読点
  • 表現・違和感 — 長文、文末の連続、近接反復、接続詞、受け身、二重否定、冗長表現など
  • 語彙・単調さ — 頻出語、抽象語、五感の偏り、語彙の多様性
  • 構成・リズム — 段落の長さ、冒頭の掴み、結び、見出しの間隔
  • note 最適化 — 長さ、使えない記法、空行、視覚要素、タイトル、有料ライン、生 URL
  • レーティング — 全年齢（厳格）／全年齢／R-18
  • リスク・配慮 — 実在の人物、個人情報、配慮表現、根拠のない断定、禁止語

レーティングの扱い

全年齢では、性的・暴力的に読まれうる語を拾い、示唆にとどめる方向の視点を返します。削れとは言いません。

R-18では性的表現そのものは指摘しません。未成年を示す語と性的文脈の共起、ゾーニング（冒頭の注意書きと露出）、官能描写の語彙の単調さを見ます。

露骨な語は内蔵辞書に入れていません。検出したい語は「設定 > ユーザー辞書 > 追加で検出したい語」に登録してください。

AI 補助（任意・既定オフ）

論理の飛躍や主張と根拠のずれなど、意味を読まないと判定できない点だけを渡します。誤字や表記揺れは規則側に任せ、プロンプトでも禁じています。返ってくるのは指摘だけで、書き換え文は求めません。

既定オフ。ボタンを押した瞬間しか送信せず、送る内容は事前に全文表示します。R-18 では localhost 以外への送信をブロックします（設定で明示的に解除しないかぎり）。外部 API より、この端末の Ollama / LM Studio / llama.cpp を勧めています。

Ollama    : http://localhost:11434/v1/chat/completions
LM Studio : http://localhost:1234/v1/chat/completions
llama.cpp : http://localhost:8080/v1/chat/completions

ブラウザから localhost に通信するには、モデル側で CORS を許す必要があります。API キーは localStorage に平文で残ります。

誤検知について

  1. 複合語ガード — 「慢性的」の中の「性的」など、漢字の複合語の一部は捨てます。
  2. 除外語リスト — 「裸足」のようにガードでは拾えないものを並べています。
  3. 確実なものだけ見る — 助詞の「のの」は「ものの」「ののしる」に当たるので外しています。

自分の文章に特有の誤検知は、指摘カードの「⊘ 今後も無視」か、ユーザー辞書の「指摘しない語」で止めてください。

読者像の推定

当てにいくのではなく、書き上げた文章を外から見るための計量です。硬さ・距離・内省・抽象度などの軸、ジャンル、想定読者、噛み合っていない点、頻出語を出します。診断タブには段落ごとの読みの負荷ヒートマップもあります。

ファイル構成の要点

アプリ本体は index.html。規則は src/core/、画面は src/ui/ です。自己テストは test.html。ローカルサーバーは serve.ps1（任意）。GitHub Pages 用に .nojekyll があります。

ルールを足す場合は Suikou.registerRule で登録し、index.html にスクリプトを足し、test.html に検証を書いてください。辞書に 1 語足すだけなら src/core/dict-language.js で足ります。

限界

  • 形態素解析器を使っていないので、語の切り出しは文字種の切り替わりによる近似です。
  • 規則だけでは文意を理解しません。論理の飛躍は AI 補助を自分で有効にしたときだけ見られます。
  • 読者像は計量からの逆算で、統計モデルではありません。
  • WXR / MT の実機検証はしていません。通らなければ「note用HTMLをコピー」を使ってください。
  • note の HTML 構造は予告なく変わります。一般的な見出し・引用・リストは拾えますが、新しいブロックは文字として入ります。
